Who can Search, Submit and Download

These are the accesses for MIS, Exception, licences and the other modules. Search, Submit, Download and Approve sit on that module’s page. Dashboard is open to every login, so it is not asked. Change a tick if a person should get something different, then go to step 2 and submit.

MIS

Daily MIS — Search the day. Submit types the daily figures. Download Excel/PDF. Approve locks or returns the day.

Monthly MIS — Search the month. Submit types only the month-only fields. Daily totals come from approved Daily MIS. Download. Approve locks or returns the month.

Cumulative Daily — read only. Search the dates and look at the table. No Submit.

Management Review — pack of Daily + Exception + Monthly already entered. Search and Download. No Submit.

Graphs — charts from Daily and Monthly. Search and Download. No Submit.

Exception

Daily Exceptions — Search the 13-point safety check. Submit types the check. Download. There is no Approve on this page.

Licences

Statutory and Mandatory — Search and Download the licence file. Submit adds or edits the licence.

Internal testing — same ticks as licences, for internal tests.

Other modules

Plant master — Search plant details. Submit edits the plant. Create or delete a plant stays Admin.

Audit — Search observations. Submit adds or updates an audit line. Download.

People — load KEKA, assign plant, turn login on or off. Admin only unless you tick it here.

If every tick is off on a module, that module is Hidden — it is not in their menu.
