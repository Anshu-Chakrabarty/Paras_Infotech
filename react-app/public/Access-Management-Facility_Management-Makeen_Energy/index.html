Access Management

For each access, pick a KEKA designation to give it to everyone with that title. The list under the pickers shows each name — Drop removes one person without dropping the designation. You can still add extra people by name on top of that. The Dashboard is open to everyone, so it is not asked here. Leave an item empty if nobody should have it.

Designations come from KEKA (the people file already loaded on this page). We do not type titles by hand. If KEKA later adds a title, it appears on the next load.
